# special-octo-carnival
Generic API Weather App


This is mostly just to add to a CV, but incase you're genuinely installing this, below is a brief summary of what this is.



It's a weather app that relies on free api keys provided by open-meteo. You change the latitude and longitude in a Python IDE (like Thonny, if you enjoy an easier life) and load it using Python version 3.10.11. I am aware that this is an old version.

Credit to Scott Cawthon for the background music.

libraries required:
Tkinter (used for gui)
pygame (used for audio handling. there's definitely a better way to do it but this is how i did it and pygame is really just one big multitool if you think about it)
requests (no requests = no api)
datetime (does what it says on the tin really)
